# Printer Test Page Generator

A simple free online printer test page generator for checking printer quality, colors, grayscale, and print alignment.

## Online Printer Test Tool

Use the online tool to generate and print printer test pages:

[Open the Printer Test Page Generator](https://kinpin768.github.io/printer-test-page-generator/)

## Features

- Black & White printer test
- Color printer test
- CMYK printer test
- Grayscale printer test
- A4 and Letter paper sizes
- Printable test pages
- Browser-based tool
- No installation required

## About

This project provides a simple browser-based way to generate printer test pages for checking print quality and printer output.

For more printer testing resources and information, visit:

[PageTestPrint - Printer Test Pages](https://pagetestprint.com/)
